SELF-SERVICE

Quick guides

Simple troubleshooting steps for common IT problems.

⌁
NETWORK

Wi-Fi not connecting

  1. Turn Wi-Fi off, wait 10 seconds, then turn it on.
  2. Check that airplane mode is disabled.
  3. Restart your router or device if possible.
  4. If it still fails, create a Network ticket.
▣
HARDWARE

Laptop running slowly

  1. Close apps and browser tabs you don't need.
  2. Restart your laptop to clear temporary issues.
  3. Check available storage space.
  4. Raise a Hardware ticket if the issue continues.
♙
ACCOUNT ACCESS

Can't sign in

  1. Check your username and keyboard layout.
  2. Confirm Caps Lock is turned off.
  3. Use the official password reset process.
  4. Never share your password in a ticket.
▧
SOFTWARE

App won't open

  1. Close the app completely and reopen it.
  2. Restart your computer.
  3. Check whether updates are available.
  4. Create a Software ticket with the error message.
