# HelpDesk — IT Support Ticket Portal

A responsive IT Helpdesk Ticket Management System built with **HTML, CSS, and vanilla JavaScript**. Created as a beginner-friendly portfolio project for demonstrating IT support workflow concepts.

## Live demo
After uploading this repository to GitHub, enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → /(root)**. Your website will be available at the URL GitHub provides.

## Features
- Dashboard with ticket totals and status breakdown
- Create tickets with requester, email, category, priority, title, and description
- Search tickets and filter by status/category
- Update ticket status: Open, In Progress, Resolved
- Delete tickets with confirmation
- Quick troubleshooting guides for common IT problems
- Responsive layout for desktop and mobile
- Light/dark theme toggle
- Saves demo data in browser `localStorage`
- Sample tickets included so the dashboard looks populated on first visit

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. No package installation or build step is required.

## Technology used
- HTML5 for structure
- CSS3 for responsive UI and dashboard styling
- JavaScript for ticket operations, filters, status changes, and local storage

## Important note
This is a **front-end demo project**. Ticket data is saved only in the current browser using `localStorage`; it is not connected to a server or real company helpdesk. Do not enter real personal or confidential information.
